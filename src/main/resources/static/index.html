Chinook Album API

Album management powered by Spring Boot and PostgreSQL

Welcome to the Album API

This REST API provides endpoints to create, retrieve, update, and delete albums in the Chinook database. Explore the available endpoints and their request formats using the interactive API documentation.

View API Documentation

Available Operations

GET

Retrieve All Albums

View the album collection at /api/albums.

GET

Retrieve One Album

Find an album by ID at /api/albums/{id}.

POST

Create an Album

Add an album using /api/albums.

PUT

Update an Album

Update an existing album at /api/albums/{id}.

DELETE

Delete an Album

Remove an album at /api/albums/{id}.
